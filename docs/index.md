# Rinha Backend 2026 — Fraud Detection API

A high-performance fraud detection scoring service built for the Rinha de Backend 2026 challenge.
Written in **.NET 9.0**, it scores financial transactions in real time using a **K-Nearest Neighbors (KNN)**
algorithm against a dataset of approximately 3 million reference transactions.
